# Участие в разработке McWire

Мы рады любой помощи! Вот краткая инструкция, как внести свой вклад.

## Ошибки и идеи
Нашли баг или хотите предложить фичу? Просто создайте **Issue** и опишите проблему.

## Как отправить код (Pull Request)
1. **Форкните** репозиторий и склонируйте его.
2. Создайте ветку: `git checkout -b feature/название` или `fix/название`.
3. Напишите код и проверьте сборку: `nimble build`.
4. Сделайте коммит с префиксом:
   * `feat:` — новая фича
   * `fix:` — исправление бага
   * `docs:` — документация
5. Отправьте **Pull Request** в ветку `dev`.

## Правила оформления
* **Шапка:** Каждый новый `.nim` файл должен начинаться с нашего копирайта:
```nim
# ==============================================================================
# McWire: Fast and lightweight Minecraft packet decoder/encoder for Nim.
# ------------------------------------------------------------------------------
# Copyright (c) 2026 CodCatDev and Contributors
# Licensed under the MIT License. See LICENSE and CONTRIBUTORS.md for details.
# URL: https://github.com/CodCatDev/McWire
# ==============================================================================
* Стиль: Стандартные отступы (4 пробела), `camelCase` для процедур, `PascalCase` для типов.

Загляните в `Roadmap` в файле `README.md`. Любой неотмеченный пункт [ ] — это задача для вас!
